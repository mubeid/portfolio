02 — Capstone Project

Capstone

// IBM Applied Data Science Capstone

Predicting SpaceX Falcon 9 First-Stage Landing Success

SpaceX reuses the Falcon 9 first stage, which is what makes its launches dramatically cheaper — so whether that stage lands is a multi-million-dollar question. This project collects launch data, explores what drives a successful landing, and builds machine-learning models to predict it, so the outcome (and therefore launch cost) can be estimated in advance.

Python Pandas SQL REST API Web Scraping Matplotlib / Seaborn Folium Plotly Dash Scikit-learn
4
Classification models compared (LogReg, SVM, Tree, KNN)
API + Web
Two data sources collected & merged
Interactive
Folium map + Dash dashboard built
  1. Collected launch data from the SpaceX REST API and by scraping Wikipedia, then cleaned and wrangled it into a single analysis-ready dataset.
  2. Ran exploratory data analysis with SQL and visualizations to surface how payload, orbit, and launch site relate to landing outcomes.
  3. Built an interactive Folium map of launch sites and a Plotly Dash dashboard for exploring success rates by site and payload.
  4. Trained and tuned four classification models with GridSearchCV, then compared accuracy to select the best predictor of landing success.
